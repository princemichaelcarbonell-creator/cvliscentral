# CVLIS Central

Static GitHub Pages version of the Camp Vicente Lim Integrated School website.

Live site: https://princemichaelcarbonell-creator.github.io/cvliscentral/

This version runs in offline/demo mode. Requests, accounts, messages, and admin changes are saved in each visitor's browser using localStorage. They are not shared between devices.

For the full server version with a shared database, use the CVLIS-Central.zip package and run `npm install` then `npm start`.
